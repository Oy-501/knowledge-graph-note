## 二、物理引擎一帧主循环（六步）

```
┌─────────────────────────────────────────────────┐
│ CPU 每一帧（60fps → dt ≈ 1/60s）                  │
│                                                  │
│ ① 施力/积分：v += (g + F/m)·dt；x += v·dt         │
│ ② BroadPhase：粗略配对（空间划分，减少检测对）      │
│ ③ NarrowPhase：Collide() 精确碰撞 → 接触点        │
│ ④ 约束求解迭代 ×10：顺序冲量法推开/摩擦             │
│ ⑤ 位置积分校正：bias 修正残余穿透                   │
│ ⑥ 休眠检测 + 清力：速度趋零的物体进入休眠           │
└─────────────────────────────────────────────────┘
```

- 位置更新是**半隐式欧拉**：先用新速度更新位置，再清力
- 迭代次数（demo 用 10）是"实时性 vs 精确性"的折中

## 三、Collide.cpp：SAT 分离轴 + 裁剪法

### 3.1 核心定理

**两个凸多边形不相交 ⇔ 存在某条轴使两者投影区间分离**。对两个 OBB，候选轴只需 4 条（各自两条边法线）：`FACE_A_X / FACE_A_Y / FACE_B_X / FACE_B_Y`。

### 3.2 核心公式（全文件最重要的 4 行）

```cpp
Vec2 faceA = Abs(dA) - hA - absC * hB;   // A 的 x/y 轴上的分离量
if (faceA.x > 0.0f || faceA.y > 0.0f) return 0;  // 该轴分离 → 不相交

Vec2 faceB = Abs(dB) - absCT * hA - hB;  // 对称检查 B 的两轴
if (faceB.x > 0.0f || faceB.y > 0.0f) return 0;
```

拆解 `faceA.x`（在 A 的 x 轴上的分离量）：

```
faceA.x = |dA.x|  −  hA.x  −  (|C11|·hB.x + |C12|·hB.y)
          B中心在    A自身     B的半宽投影到A.x轴的"最坏情况"
          A局部系     半宽      （absC 取绝对值保证不穿透）
```

- `dA = RotAT·(posB − posA)`：B 相对 A 的位置，转到 A 局部系
- `C = RotAT·RotB`：B 的旋转相对 A 的旋转
- 用 `absC` 而非 `C`：投影半径取最大值（|cosθ|·hx + |sinθ|·hy），防幽灵穿透

### 3.3 选参考面（防抖容差）

选分离量最小的轴作参考面；`relativeTol = 0.95` + `absoluteTol = 0.01` 要求新轴**显著更小**才切换，防止两轴分离量相近时每帧在参考面之间跳变（接触点抖动）。

### 3.4 裁剪法生成接触点（面-面接触）

1. `ComputeIncidentEdge`：把参考面法向转到对方局部系取反，按 `nAbs.x > nAbs.y` 判断选横边还是竖边 → 找最贴参考面的入射边
2. `ClipSegmentToLine` **两次裁剪**（Sutherland–Hodgman）：用参考面两条侧边夹击入射边，保留下接触段
3. 接触段上 `separation <= 0` 的点（穿入参考面）沿法向滑回参考面 → 输出 **1~2 个接触点** + 特征对 `FeaturePair`

**为什么 1~2 个点**：面贴面时接触区域是线段，单点接触是病态的；多个接触点构成**接触流形**，求解器分布冲量后堆叠才稳定。

## 四、Arbiter.cpp：顺序冲量法（Sequential Impulse）

### 4.1 一句话

**不一次性解所有接触约束的联立方程，每轮迭代只解一个接触点、应用一次冲量、更新速度，重复 N 次直到收敛。**

### 4.2 三个函数分工

| 函数 | 职责 |
|---|---|
| 构造函数 + Update | 调 Collide 生成接触点；**特征匹配 + 热启动**（继承上帧冲量） |
| PreStep | 预计算每点**等效质量** massNormal/massTangent 和 **bias**（穿透修正速度） |
| ApplyImpulse | 解一个接触点：**法向冲量 + 摩擦冲量**，更新速度（迭代 N 次） |

### 4.3 关键实现细节

**热启动（warm starting）**——Update 里用 `feature.value` 匹配新旧接触点，继承 `Pn/Pt/Pnb`。堆叠物体每帧接触点几乎不变，冲量继承后每帧从"接近解"出发，一叠箱子稳站不塌不抖。

**等效质量（PreStep）**：

```
kNormal = invMass1 + invMass2
        + invI1·(|r1|² − (r1·n)²) + invI2·(|r2|² − (r2·n)²)
massNormal = 1 / kNormal
```

冲量增量 = 等效质量 × 待消除速度（J = m·Δv 的接触点版本）；`(r×n)² = |r|² − (r·n)²` 是 2D 转动贡献。

**Baumgarte 位置校正（bias）**：

```cpp
c->bias = -k_biasFactor * inv_dt * Min(0.0f, c->separation + k_allowedPenetration);
// k_allowedPenetration = 0.01 允许微小穿透防抖动；k_biasFactor = 0.2
// 穿透超过 1cm 时，伪造一个向外"推"的目标速度，让求解器自然推出穿透区
```

**ApplyImpulse 核心**（每轮迭代）：

```
① dv = v2 + ω2×r2 − v1 − ω1×r1       相对速度
② vn = dv·n                          法向速度
③ dPn = massNormal·(−vn + bias)      冲量增量
④ Pn = max(Pn0 + dPn, 0)             clamp：接触只能推不能拉
⑤ 应用法向：v1 −= invM·Pn·n；ω1 −= invI·(r1×Pn·n)；v2/ω2 反向
⑥ vt = dv·t                          切向速度（滑动）
⑦ dPt = massTangent·(−vt)            摩擦冲量
⑧ |Pt| ≤ μ·Pn（库仑摩擦锥）          clamp：|Pt| 不超过 μ×法向冲量
⑨ 应用切向冲量
```

### 4.4 面试必答三点

1. **为什么迭代而不是直接解方程？** 接触约束全局耦合、稀疏；直接解 LCP 昂贵且数值不稳。顺序冲量是 Gauss-Seidel 式迭代逼近，10~20 次足够视觉收敛。
2. **为什么热启动这么关键？** 堆叠物体每帧接触点几乎不变，冲量继承后每帧只微调；否则每帧从零重建整叠箱子的力平衡，会抖动甚至塌掉。
3. **bias 是速度修正还是位置修正？** 表面是速度（伪造目标速度），本质是 Baumgarte 位置修正；允许 0.01m 穿透防数值抖动。

## 五、无头验证（本地可复现）

```bash
# Linux 云环境
cmake -DBOX2D_BUILD_SAMPLES=OFF && make   # 产出 libbox2d-lite.a
g++ -O2 -std=c++11 -Iinclude demo_nohead.cpp src/Arbiter.cpp src/Body.cpp src/Collide.cpp src/Joint.cpp src/World.cpp -o demo_nohead
./demo_nohead
```

测试场景：地面（mass=FLT_MAX 静态）+ boxA(m=5, y=5) + boxB(m=2, y=10)，重力 (0,−10)，60fps 步进 120 帧。

**PASS 结果**：boxA 停在 y=0.490（≈半高 0.5 − 允许穿透 0.01），boxB 停在 1.480，速度归零，无幽灵穿透。
