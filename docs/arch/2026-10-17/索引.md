## 三、三块工作分别是什么

### 1. 反向链接收尾（Obsidian 模式）

点图谱节点 → 抽屉里显示「哪些笔记写过这个知识点」，分**已关联 / 提到·未关联**两段。
后半段不是凑数：它把「知识已在笔记里、只是没连」的部分捞出来，是补齐关联最快的地方。
链路：NodeDetailDrawer → GraphCanvas → App.vue → 切到工作台 → workbenchRef.openNote(id)。

### 2. 界面设计器 Theme Studio

用户能在网页里自己设计整套界面。核心克制是：**调体系，不调零件**——
暴露的是六个系统级维度（色相 / 密度 / 圆角 / 通透 / 颗粒 / 展示字），一条 slider 下去全站响应。
强调色用 oklch 锁定明度彩度只转色相，所以任何取值都不会刺眼；朱砂作为品牌印记不参与个性化。
这样既给足自由度，又不会退化成「某个按钮比周围亮一档」的补丁感。

### 3. 判定链路优化

按 document-split-verdict-admin 全量复盘后，发现链路本身早已完整，
于是改的是三处「写对了但还能打磨」的地方：

1. **批量入库把关系重建做了 N 遍** → 加 `defer_relations`，批尾只重建一次。
2. **重跑判定会推翻人工裁决** → `skip_human` 默认跳过，要覆盖必须显式 `force`。
3. **`merged` 是个死字段** → `_merge_twins()` 把同实体的重复候选归并，不再占着待审队列。
