## 四、关键链路调用路径

### 上传 → 切割 → 抽取 → 候选 → 判定 → 审计

```
api/files.py::upload
  └─ services/parser.py::parse_and_extract
       ├─ services/file_splitter.py::plan_split          # 结构边界切分
       ├─ services/file_splitter.py::validate_plan       # 覆盖率/撕裂校验
       ├─ services/parser.py::extract_nodes_from_text    # 逐片抽取
       │    ├─ services/text_role.py::line_role          # 标题/正文判别
       │    └─ services/parser.py::extract_entity        # 实体抽取（无标题兜底）
       ├─ services/vector_engine.py::embed_to_db         # 向量化
       ├─ services/kb_index.py / kb_link.py              # 知识库锚定与桥接
       ├─ services/inference.py                          # 四维关联
       └─ services/parser.py::create_candidates_and_verify
            ├─ services/knowledge_verifier.py::verify_candidate
            │    ├─ 规则：parser 标题形态 / 定义句式
            │    ├─ 知识库：kb_index
            │    ├─ 图谱：节点连线
            │    └─ 联网：web_probe.search_web → web_existence.check_existence
            └─ services/audit.py::log_event             # 判定依据落审计
```

### 后台审阅

```
kg-vue3/src/components/AdminView.vue
  └─ kg-vue3/src/api/index.js
       └─ backend/app/api/admin.py
            ├─ GET  /api/admin/candidates
            ├─ POST /api/admin/candidates/{id}/review
            ├─ POST /api/admin/candidates/bulk-review
            └─ GET  /api/admin/audit
```

### 图谱总结与导出

```
kg-vue3/src/components/GraphSummaryView.vue
  └─ backend/app/api/summary.py
       ├─ POST /api/summary/build   → services/graph_summary.py::build_summary
       ├─ GET  /api/summary/mermaid
       └─ GET  /api/summary/download → services/summary_export.py
```

### 登录

```
LoginView.vue → authStore → POST /api/auth/login
  → services/auth_service.py（bcrypt + 会话）
  → 会话令牌 X-Session-Token，写入 localStorage
```

## 五、运行与部署入口

| 场景 | 命令 / 路径 |
|---|---|
| 开发（热更新） | `python scripts/dev.py`，或 `bash start.sh` / `启动服务.bat` |
| 生产预览 | `python scripts/dev.py --prod` |
| Docker 部署 | `docker compose up -d --build`（配置 `.env.docker.example` → `.env`） |
| 静态体检 | `cd backend && py scripts/check.py` |
| 全量测试 | `cd backend && py -m pytest` |
| 功能验收 | `py backend/scripts/acceptance_audit.py` |
| 边界矩阵 | `py backend/scripts/boundary_matrix.py` |
| 打分发包 | `python scripts/package.py` → `dist/*.zip` |
