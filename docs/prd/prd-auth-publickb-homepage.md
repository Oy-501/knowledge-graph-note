# 增量 PRD：用户认证 + 公共知识库 + 哔哩哔哩式个人主页

## 1. 项目信息

- **Language**: 中文
- **Programming Language**: 既有技术栈延续 —— Electron 外壳 + FastAPI 后端（`backend/app`）+ Vue3 前端（`kg-vue3/src`）+ SQLite
- **Project Name**: kg_notes_auth_home
- **原始需求复述**：在既有知识图谱笔记系统上增量开发：① 用户登录页与用户信息库，改掉 ADMIN_TOKEN 明文口令问题；② 所有验证过的知识点进入多用户共享的公共知识库；③ 数据存储管理页放入管理员页，需正式的管理员账号体系；④ 哔哩哔哩式个人主页（日记 / 知识图谱入口 / 收藏 / 个人相册含视频转码），并设为第一个页签。
- **已确认决策**：多用户共享账号体系（可注册/登录、公共库互通、可收藏他人分享）；视频支持常见格式 + 大视频 ffmpeg 转码。

## 2. 产品定义

### 2.1 Product Goals

1. **建立安全的多用户账号体系**：注册/登录/加密存储/会话令牌/管理员账号，彻底替换明文 ADMIN_TOKEN 机制。
2. **知识资产公共化**：验证通过的知识点自动进入公共知识库，支持跨用户浏览与收藏，形成社区知识沉淀。
3. **以个人主页为核心的产品形态**：主页成为默认页签，整合日记、图谱入口、收藏、相册四大板块，提供「个人空间」体验。

### 2.2 User Stories

**普通用户**

1. As a 普通用户，I want 注册账号并用账号密码登录，so that 我的数据与身份被独立管理。
   - 验收：注册重复用户名被拒绝并提示；错误密码返回明确错误；登录成功后进入个人主页；重启应用后凭有效令牌免登录。
2. As a 普通用户，I want 我的密码不以明文存储、不被界面暴露，so that 账号安全有保障。
   - 验收：数据库中密码字段为哈希值；任何接口/页面不回显密码；旧 ADMIN_TOKEN 明文配置被移除。
3. As a 普通用户，I want 在主页写日记并查看历史日记，so that 我有私人的记录空间。
   - 验收：可新建/编辑/删除日记；日记仅本人可见；按时间倒序展示。
4. As a 普通用户，I want 从主页一键进入知识图谱，so that 图谱是我工作流的一部分。
   - 验收：主页「知识图谱」板块点击后跳转到图谱页签。
5. As a 普通用户，I want 浏览公共知识库并收藏他人已验证的知识点，so that 我能复用社区知识。
   - 验收：公共库列表可见他人已验证知识点（含作者署名）；点击收藏后出现在我的「收藏」板块；取消收藏即时生效。
6. As a 普通用户，I want 上传图片和视频到个人相册，so that 我能管理个人多媒体素材。
   - 验收：常见图片格式（jpg/png/gif/webp）直接展示；常见视频格式（mp4/webm/mov 等）可播放；超出阈值的大视频自动转码后再展示；上传过程有进度与失败提示。

**管理员**

1. As a 管理员，I want 用独立的管理员账号密码登录管理后台，so that 管理权限不再依赖明文 Token。
   - 验收：存在管理员账号（区别于普通用户）；AdminView 需管理员会话才能访问；普通用户访问被拦截。
2. As a 管理员，I want 在管理员页看到数据存储管理板块，so that 我能掌握系统数据状况。
   - 验收：管理员页内有「数据存储管理」板块，展示数据库大小、媒体文件占用、用户/知识点/收藏数量统计。
3. As a 管理员，I want 管理用户（查看/禁用），so that 公共环境可控。
   - 验收：用户列表可见全部注册用户；可禁用/启用账号；被禁用用户无法登录且会话失效。
4. As a 管理员，I want 管理公共知识库内容（下架违规知识点），so that 公共内容质量可控。
   - 验收：管理员可将公共库知识点下架，下架后对普通用户不可见，作者本人仍可见。

## 5. 待确认问题（Open Questions）

1. **注册开放策略**：是否任何人都能注册，还是仅管理员创建账号？（建议：毕设场景开放注册即可，管理员可禁用账号兜底）
2. **既有数据归属**：当前单用户数据（知识点、素材、Profile 信息）在引入多用户后归属哪个账号？（建议：首次启动引导创建一个「主账号」并自动迁移既有数据）
3. **公共库可见范围**：「已验证」知识点是**自动**进公共库，还是需作者勾选「分享」？（建议：按需求字面自动进入，但保留「取消分享」开关更稳妥）
4. **视频转码阈值与规格**：多大算「大视频」、转成什么规格？（建议：>50MB 触发转码，输出 720p H.264 mp4；ffmpeg 需随应用打包或检测本机环境）
5. **上传体积上限**：相册单文件/总配额是否限制？（建议：单文件 500MB、每用户 2GB，可配置）
6. **会话有效期与多端**：令牌有效期多长、是否允许多端同时在线？（建议：7 天滑动过期；本地应用暂不限制多端）
7. **日记格式**：纯文本还是富文本/Markdown？（建议：Markdown，与现有笔记体系一致）
8. **管理员初始化方式**：首个管理员账号如何创建？（建议：首次启动初始化向导或环境变量注入，二选一）

## 6. 边界（Scope）

**In（本次做）**
- 多用户注册/登录/登出、密码哈希、会话令牌、角色（普通/管理员）
- 移除明文 ADMIN_TOKEN，后台接口全面接入会话鉴权
- 公共知识库（已验证知识点自动汇入 + 作者署名）与收藏
- 个人主页四板块（日记/图谱入口/收藏/相册），设为第一个页签
- 相册支持图片与常见视频格式，大视频 ffmpeg 异步转码
- 管理员页新增：数据存储管理、用户管理、公共库内容管理

**Out（本次不做）**
- 第三方登录（微信/GitHub OAuth）、邮箱验证、找回密码
- 用户间社交功能（关注、私信、评论、点赞）
- 日记的多人协作/公开分享
- 公共知识库的审核工作流（沿用现有「已验证」状态即可，不做二次审核）
- 移动端适配、云端同步（仍为本地应用）
- 视频在线剪辑、字幕、封面自定义等增强能力
