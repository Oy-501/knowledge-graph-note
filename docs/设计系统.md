# 设计系统

> **本文件是 UI 设计的唯一权威来源。** 改样式、加组件、调主题之前先读这里。
>
> 两句话概括这套系统：
> 1. **个性属于「标识」，不属于「容器」** —— 一个模块一种颜色、只占几像素、只出现在「你在哪」的位置。
> 2. **静止的东西不该发光** —— 光只用来表示「现在被操作的是这里」。
>
> 历史修复记录（字号体系、空态、错误态等是怎么改出来的）见 `docs/UI设计优化说明.md`。

## 一、先说问题：碎裂是量出来的

改造前对 `kg-vue3/src` 做过一次统计：

| 指标 | 数量 | 意味着什么 |
|---|---|---|
| card / panel / block / box 类名 | **39 个** | 同一个「卡片」有 39 份实现 |
| btn / button 类名 | **59 个** | 同一个「按钮」有 59 份实现 |
| border-radius 取值 | **11 种** | 圆角不构成系统，只是各写各的 |
| box-shadow 调用 | **90+ 处**，21 个组件 | 层级靠阴影堆，越堆越脏 |

单看每一处都合理（半径差 2px、阴影差一级），放在同一屏就是「杂乱」——
因为**没有两个东西是同一个东西**。

### 突兀的三个真正原因

1. **个性落在了容器上**：整块底色、整排按钮换色。容器是「功能的形状」，
   它一变，用户会以为功能语义变了（主次、危险、成功）。
2. **每次个性化都是新写一份 CSS**：不是复用同一套再调参数，而是复制一份再改。
3. **没有强调预算**：一屏 6 个实心按钮同时喊，等于没人喊。

## 二、四种可选方法（本项目的取法）

| 方法 | 做法 | 代价 |
|---|---|---|
| **A. 组件原语 + 变体** | 卡片/按钮/标签各只写一次，差异用变体表达 | 需一次性收敛旧代码 |
| **B. 强调预算** | 每屏只允许 1 个 loud | 要有人守规则 |
| **C. 模块作用域令牌** | `[data-module]` 只注入 1 个 `--mark` | 个性表达力有限（只有标记） |
| **D. 静默默认、交互发声** | 个性只在 hover / focus 出现 | 移动端没有 hover |

本项目取 **A + B + C**，D 只用在动效细节上（按压下沉 1px，不做悬浮位移）。

## 三、Token 全表

全部定义在 `styles/main.css`（暗色在 `html.dark` 里重映射）。
**组件只消费变量名，不写具体色值。**

### 表面层级（亮 / 冷调浅灰，不是纯白）

| Token | 亮色值 | 用途 |
|---|---|---|
| `--bg-deep` | `#E7EAF2` | 应用外框 / 工作台包围色 |
| `--bg-primary` | `#F2F4F9` | 主面板 |
| `--bg-secondary` | `#FFFFFF` | 卡片 / 抬升面板 |
| `--bg-tertiary` | `#E9EDF5` | 嵌套块 / 胶囊底 |
| `--bg-hover` | `#DFE4EF` | 悬浮态 |
| `--bg-active` | `#D3DAE8` | 激活按压 |
| `--bg-glass` | `rgba(255,255,255,.70)` | 毛玻璃表面 |

为什么不做纯白：纯白底上玻璃拟态与辉光完全不可见，整套视觉语言会退化成普通后台。

### 半透明表面（视图根容器必须透明，卡片才有通透感）

```
--surface-1: color-mix(--bg-secondary 90%, transparent)   卡片
--surface-2: color-mix(--bg-secondary 82%, transparent)   次级
--surface-3: color-mix(--bg-primary   88%, transparent)   内嵌
```

透明度不低于 0.82：文字对比度是按**不透明**底色校准的，再低就读不清了。

### 文字层级

| Token | 值 | 说明 |
|---|---|---|
| `--text-primary` | `#101725` | 正文与标题 |
| `--text-secondary` | `#4A5670` | 次级信息 |
| `--text-muted` | `#57637C` | 辅助说明（最差底色上仍达 4.73:1） |
| `--text-faint` | `#8C97AB` | 极弱提示、禁用态 |

### 强调色（青）

| Token | 亮色 | 暗色 |
|---|---|---|
| `--accent` | `#0C6B84` | `#22D3EE` |
| `--accent-light` | `#0891B2` | `#67E8F9` |
| `--accent-strong` | `#0A6076` | `#06B6D4` |
| `--accent-fill` | `#0E7490` | `#22D3EE` |
| `--accent-soft` | `rgba(8,145,178,.11)` | `rgba(34,211,238,.13)` |

**填充面与文字色拆成两对**（`--accent-fill` / `--on-accent`）：
霓虹色做「填充」和做「文字」需要的明度是相反的，同一个变量兼顾不了，
否则实心按钮上的白字读不清。

### 语义色

四组语义色，每组都拆「填充面 + 前景」一对（填充面要承白字，文字色要在浅底上够深）：

| 组 | 填充面 `--*-fill` | 文字/描边 `--*` | 前景 `--on-*` |
|---|---|---|---|
| success | `#0F7B5C` | `#0C6B4F` | 白 |
| warning | `#B45309` | `#A34A08` | 白 |
| danger | `#BE2E3E` | `#BE2E3E` | 白 |
| info | `#0E7490` | `#0E7490` | 白 |

另有各自的 `-soft` 底（`rgba(…, .11~.13)`）用于淡底徽标。

辅色：**紫** `--violet` `#7C3AED`（文字用 `--violet-text` `#7C3AED`）、
**琥珀** `--amber` `#A34A08`、**品红** `--magenta` `#BE185D`。

> 旧别名 `--mint` → 紫、`--apricot` → 琥珀。全站 40+ 处引用，
> **保留别名不改名**：改名收益远小于断链风险。

### 分隔线 / 阴影

```
--border        #CFD6E4     常规边框
--border-light  #DFE4EE     卡片内部弱边框
--shadow-sm/md/lg/card/card-hover   柔和投影（亮色不加辉光，会糊成脏边）
```

### 字号体系（六档）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 11px | 徽标、角标、快捷键（下限，仅极短文本） |
| `--fs-sm` | 12px | 次级信息、时间戳、辅助说明 |
| `--fs-md` | 13px | 正文与标签、按钮文字 |
| `--fs-base` | 14px | 正文基准 |
| `--fs-lg` | 16px | 小标题 |
| `--fs-xl` | 18px | 区块标题 |

下限刻意定在 11px：10px 及以下在 1x 屏上接近不可读，中文小字尤其吃力。

### 圆角 / 尺寸

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 控件（近，指哪打哪） |
| `--radius` | 10px | 卡片（中） |
| `--radius-lg` | 14px | 浮层 / 弹窗（远） |
| `--radius-full` | 999px | 胶囊 |
| `--ctrl-h` | 30px | 控件基准高度（密度调节靠它） |
| `--panel-width` | 288px | 左侧面板 |
| `--toolbar-height` | 56px | 工具栏 |

只有三档圆角，**不要出现 4 / 8 / 12 这些中间值** —— 差 2px 说不出理由，只会显得没对齐。

### 字体

```
--font-sans     -apple-system / 'Segoe UI' / 'PingFang SC' / 'Microsoft YaHei'  正文
--font-mono     'JetBrains Mono' / 'Fira Code' / Consolas                        数据、编号、代码
--font-display  'Noto Serif SC' / 'Songti SC' / 'SimSun'  (identity.css)         ≥18px 标题与品牌
```

展示字只在 ≥18px 用：宋体小字在 1x 屏上发虚。

### 动效

```
--ease-out  cubic-bezier(0.22, 0.61, 0.36, 1)
--dur-fast  0.15s     颜色、边框这类即时反馈
--dur-base  0.25s     面板、抽屉
```

## 四、样式层序（顺序即优先级）

`main.js` 里的引入顺序，后加载的覆盖先加载的，**不要调换**：

```
1. main.css        令牌（色彩/字号/圆角/动效）
2. primitives.css  组件原语（.u-btn / .u-surface / .u-chip …）
3. texture.css     素材层（--tex-* 槽位、颗粒）注释此行即回到纯令牌视觉
4. ai-ui.css       交互增强（悬停/聚焦/过渡）注释此行即整体回退
5. identity.css    身份层（朱砂、印章、菱形导引符）★ 必须靠后
6. modules.css     模块令牌（--mark）
```

踩过的坑：画布网格改在 `main.css` 里不生效，因为 `texture.css` 后加载、
它的彩色光斑一直在覆盖。**样式层叠里「谁后加载」比「谁写得详细」更常见。**

## 五、机制一：模块令牌 `--mark`

### 契约

```
个性 = 一个模块一个色，只出现在标记位。
```

允许消费 `--mark` 的位置，全站就这四处，**不要再加**：

| 位置 | 文件 | 尺寸 |
|---|---|---|
| 导航当前页下划线 | `identity.css` `.nav-tab.active::after` | 2px |
| 页面标题前的菱形 | `identity.css` `.app-view h2::before` | 7px |
| 栏目眉标的栏号与短横线 | `primitives.css` `.u-kicker__no / __rule` | 11px 文字 |
| 分节标题的栏号 | `primitives.css` `.u-sec-title__no` | 12px 文字 |

**禁止**：给按钮、卡片、表格、输入框、图表换色。

### 怎么加一个模块

在 `styles/modules.css` 加一行，再在 `App.vue` 的 `NAV_TABS` 加页签。
根节点已绑 `:data-module="currentView"`，令牌自动生效，不用改组件。

```css
[data-module="mymodule"] { --mark: var(--violet-text); }
```

### 取色规则

只从已有语义色取：青 / 紫 / 琥珀 / 朱砂 / 墨。**不引入新色相**。

| 模块 | 色 | 为什么 |
|---|---|---|
| 知识图谱 | 青 | 数据、结构、仪表感 |
| 知识工作台 | 紫 | 创作，与「读」区分 |
| 知识库 | 琥珀 | 权威源 |
| 图谱总结 | 朱砂 | 报告/刊物，与产品印记同色 |
| 个人主页 | 青 | 同属数据视图 |
| 界面设计 | 紫 | 产出物 |
| 后台管理 | 墨 | 工具页，不给色相 |
| 函数图像 | 青 | 可视化 |
| 背景 CSS | 紫 | 产出物 |

## 六、机制二：组件原语

文件 `styles/primitives.css`。**新组件从这里取，不要另起 `.my-card` / `.xx-btn`。**

### 表面

```html
<div class="u-surface">            默认：半透明面 + 1px 边
<div class="u-surface u-surface--flat">   无壳，靠发丝线分段
<div class="u-surface u-surface--inset">  内嵌块
```

### 按钮（强调从高到低）

```html
<button class="u-btn u-btn--solid">    主操作，一屏最多一个
<button class="u-btn u-btn--seal">     品牌级/一次性动作
<button class="u-btn u-btn--tonal">    次操作
<button class="u-btn u-btn--outline">  次要，需要明确边界
<button class="u-btn u-btn--ghost">    工具条里的普通动作
<button class="u-btn u-btn--text">     导出/复制这类收尾动作
```

状态：`hover` 只改底色（`filter: brightness(1.06)`），**不做 translateY**；
`active` 下沉 1px；`focus-visible` 2px 青环；`disabled` 45% 透明。
高度走 `--ctrl-h`，不写死 30px。

### 标签 / 眉标 / 分节标题 / 发丝线

```html
<span class="u-chip">标签</span>
<span class="u-chip u-chip--on">选中</span>

<div class="u-kicker">
  <span class="u-kicker__no">NO. 07</span>
  <span class="u-kicker__rule"></span>
  <span>知识图谱总结</span>
</div>

<header class="u-sec-title">
  <span class="u-sec-title__no">03</span>
  <h3>总结流程图</h3>
  <span class="u-sec-title__note">说明</span>
  <span class="u-sec-title__fill"></span>      <!-- 发丝线 -->
  <span class="u-sec-title__actions">…</span>
</header>
```

发丝线用**显式元素**而不是 `::after`：有右侧操作时线要停在操作之前，
`::after` 只能排最后，线会跑到按钮右边的空白里。

### 强调预算

```html
<div data-emphasis="quiet">这块压成次级色</div>
```

一条页面：**1 个 loud + 若干 normal + 需要的 quiet**。
判断方法：眯眼看这一屏，能一眼找到唯一重点就算通过。

## 七、身份层（`identity.css`）

这一层只做三件事，不改任何组件结构。

| 元素 | 说明 |
|---|---|
| `--seal` 朱砂 | 亮 `#b8362a` / 暗 `#dc4a32`。**身份色，不是交互色** |
| `.app-seal` 印章 | 26px、朱砂底、`-3°` 旋转（摆正就成了普通方块）、内描边。与落地页同一枚 |
| 页面标题菱形 | `.app-view h2::before`，7px 旋转 45°，吃 `--mark` |
| `--font-display` | 衬线展示字，只用于 ≥18px 标题与品牌 |
| `--rule` | 发丝线，`color-mix(text-primary 22%)` |

**为什么强调色仍是青、不换成朱砂**：朱砂与 `--danger` 同属红区，
一旦拿它当交互色，按钮、链接、错误提示会混成一片——「危险」就不再是危险。
所以朱砂限定为身份色，交互色继续由 `--accent` 负责。

## 八、素材层与画布

### 素材槽位（`texture.css`）

素材由 `.app-tex` 三层渲染，槽位变量 `--tex-*` 控制。
颗粒强度 `--tex-grain-opacity` 默认 0.14（亮）/ 0.16（暗）——
职责是「打散色带」，0.35 以上会像压缩噪点而不是纸纹。

**视图根容器一律透明**（`background: transparent`），
卡片用半透明 `--surface-*`。若根容器写不透明底色，素材层会被整块盖掉——
「换背景没反应」就是这么来的。

### 背景两套机制并存，别互相盖

- 现行：素材槽位 `--tex-*` → `.app-tex`（三层）
- 旧：单层 `--editor-bg` → `.app-global-bg`

一个背景只能由一个层画。旧变量没配置时必须 `removeProperty`，
不能写不透明兜底（那会让样式表里的 `transparent` 变成死代码）。

### 画布（图谱主体）

- 28px 细网格提供空间尺度 + 暗色专属暗角提供边界
- 网格色 `color-mix(text-primary 5%)`，亮暗自动跟随
- 力导：<800 节点斥力 −300、碰撞半径 +11；≥800 降低斥力优先收敛
- `fitToView()` 只在 `event.sourceEvent` 为空时执行（用户手动缩放后不再覆盖他的视角）

## 九、界面设计器（Theme Studio）

第 9 个页签，用户可在网页里自己设计整套界面。
核心克制：**调体系，不调零件**——只暴露六个系统级维度，一条 slider 全站响应。

| 维度 | 下发到 | 说明 |
|---|---|---|
| 色相 hue | `--accent` 家族 | oklch **锁定明度彩度只转色相**，任何取值都不会刺眼 |
| 密度 density | `--fs-*` + `--ctrl-h` | 字号与控件高度**同一系数**，否则会变成「小字挤在大盒子」 |
| 圆角 radius | 三档等比 | 不新增中间值 |
| 通透 surface | `--surface-1/2/3` | 三档按 0.90 / 0.82 / 0.88 比例联动 |
| 颗粒 grain | `--tex-grain-opacity` | |
| 展示字 display | `--font-display` | 衬线 / 黑体 |

**朱砂 `--seal` 不入个性化**——它是品牌印记不是皮肤变量，
守住这条，再怎么调也还是同一个产品。

状态与下发：`store/themeStore.js`（localStorage 持久化 + 导出/导入 JSON）。
accent 派生依赖明暗，所以主题 `load()` 必须在 `settingsStore.load()` **之后**
（暗/亮类是后者打在 `<html>` 上的）。

## 十、安静精密：四条硬规则

第一版解决了「碎裂」，但界面仍吵，原因是**发光太多**：
节点 hover 发光、选中双环、按钮扫光、卡片边缘渐变光、画布三团彩色光斑、
26 秒一次的极光漂移……合起来是「每样东西都在说话」。

### 规则 1：静止时不发光、不流动

> 如果一个效果在**静止状态**下就在发光或移动，它就不是交互反馈，而是装饰。

- 节点 hover：`stroke-width: 2` + 同色 `brightness(1.18)`，**不用 drop-shadow**
- 选中：主色 2px 描边 + 极淡提亮（SVG `<circle>` 不支持 inset 阴影，不硬造）
- 按钮：删掉 shimmer 扫光（扫光是「加载中」的语汇，按钮是「现在可以点」）
- 卡片：删掉青→紫渐变边缘光，hover 只提 `--bg-hover`
- 数值：渐变字改纯色 + `tabular-nums`（渐变会让读数变难）

### 规则 2：背景是背景，不能当第二个主体

画布原先三层彩色径向渐变 + `blur(52px)` 极光漂移，60% 面积被染色，
眼睛先在光斑之间找关系才去看图。现在改为 28px 网格 + 暗角。

### 规则 3：一个交互主色

`--accent` 独占所有交互（链接、选中、焦点、滑块、开关）。
`--violet` 降级为**纯数据语义**（层级徽章、图谱簇着色），
禁止出现在按钮、滑块、选中态上。

### 规则 4：字号有下限，位移有配额

- 面板内正文/说明 ≥ 12px；只有角标、计数、序号、快捷键、纯图标保留 11px
- 图谱标签 12px 起（字号是 D3 内联设置的，改 CSS `.node-label` 无效）
- `translateY(-2px)` 上浮**只留给卡片**；列表项、按钮、上传区只改底色

## 十一、禁忌清单

| 不要做 | 为什么 |
|---|---|
| 在组件里手写新卡片 / 新按钮样式 | 39 / 59 份实现就是这么来的，用 `.u-*` 原语 |
| 给按钮、卡片、输入框换色做「个性」 | 容器变=功能语义变；个性走 `--mark` 标记位 |
| 引入新的圆角中间值（4/8/12） | 差 2px 说不出理由，只会显得没对齐 |
| 用 `drop-shadow` 做 hover / 选中反馈 | 静止就发光 = 装饰；用描边加粗 + brightness |
| 给按钮加 `translateY` 悬浮 | 满屏都在动比满屏都在喊更吵；位移只给卡片 |
| 一屏放两个以上实心（loud）按钮 | 人人都喊等于没人喊 |
| 用 `::after` 画分节头的发丝线 | 有右侧操作时线会跑到按钮右边空白里 |
| 视图根容器写不透明背景 | 会整块盖掉素材层，「换背景没反应」 |
| 拿朱砂当交互色 | 与 `--danger` 同属红区，危险语义会失效 |
| 直接改 `--mint` / `--apricot` 的定义 | 全站 40+ 处引用，它们是别名 |
| 在 D3 里内联字号后指望 CSS 覆盖 | 内联优先级更高，要改 `labelFontSize()` |

## 十二、可达性与降级

### 对比度

- 正文 ≥ **4.5 : 1**，大字（≥18px 或粗体 14px+）≥ **3 : 1**
- 导航激活项曾用 `--accent-light`（**2.79 : 1**，连大字标准都不到，
  当前页几乎看不清），现已提到约 **5.9 : 1**
- 非激活页签也从 `--text-muted`（约 2.4 : 1）提到 `--text-secondary`（约 4.5 : 1）
  —— 导航是主要入口，不该用装饰性灰

### 不单靠颜色传达状态

- **导航当前页**：除颜色外叠加内描边（`inset box-shadow`），色觉障碍用户也能分辨
- **自检列表**：每行左侧 3px 色条（通过 / 警告 / 错误），不只有颜色

### 键盘可达性

- 全站 `:focus-visible` 焦点环：**2px 品牌色 + 2px offset**，
  只在键盘导航时出现，鼠标点击不显示 —— 兼顾可达性与视觉整洁
- 导航页签补齐 `role="tablist"` / `role="tab"` / `aria-selected` / `aria-controls`；
  图标按钮补 `aria-label`
- 快捷键 **Ctrl / ⌘ + 1~N** 切页签（焦点在输入框内时不劫持）；
  页签显示极淡的快捷键徽标，悬停 / 聚焦 / 激活时显现

### 动效降级

```css
@media (prefers-reduced-motion: reduce) { /* 关闭全部动画与过渡 */ }
```

对前庭功能敏感的用户，这个系统设置是**明确的用户意图**，不是偏好。

### 窄屏与溢出

导航在窄窗口横向滚动（`overflow-x: auto` + 隐藏滚动条 + `flex-shrink: 0` +
`white-space: nowrap` 防文字换行导致高度跳动），切页签时把激活项滚入可视区。

`check_design_doc.py` 防止这份文档说谎：改了 `main.css` 里的色值却忘了同步文档，
它会报出「文档里没出现这个值」。文档过期比没有文档更危险 ——
人会照着它写新代码。

`aesthetic_check` 实测：画布 `background-image` 只剩 linear-gradient、
节点静止 `filter=none`、主按钮 `box-shadow=none`、全站 `text-transform: uppercase` 数量为 0。
