## KB-CONCEPTS (已被知识库锚定的知识点)
- 前端开发 (锚定 7 个节点): 前端开发关注用户界面，以 JavaScript 为核心语言。React 和 Vue 是前端开发的两大框架。TypeScript 在前端开发中越来越普及。Webpack 是前端开发的模块打包工具。前端开发涉及 HTML 和 CSS 基础技术。
- JavaScript (锚定 6 个节点): JavaScript 是浏览器端唯一原生编程语言，操控 DOM 与事件循环，是前端框架与异步任务的基础。
- Java (锚定 6 个节点): Java 是企业级后端开发的主流语言，基于 JVM 运行。Spring 框架是 Java 生态的核心，广泛用于微服务架构。Maven 是 Java 项目的主要构建工具。Java 在大规模分布式系统中表现稳定。
- Node.js (锚定 6 个节点): Node.js 是基于 V8 引擎的 JavaScript 运行时，让 JavaScript 可以用于后端开发。Express 是 Node.js 上最流行的 Web 框架。npm 是 Node.js 的包管理器，拥有全球最大的开源库生态…
- 结构 (锚定 5 个节点): 结构是作品的整体框架。结构体现在大纲和章节中。结构与情节和叙事相关。好的结构让情节更紧凑。结构有三幕剧、英雄之旅等模式。结构是写作的骨架。
- SQL (锚定 5 个节点): SQL 是结构化查询语言，用于操作关系型数据库。MySQL 和 PostgreSQL 都支持 SQL。SQL 是数据库领域的通用语言。SQL 与 NoSQL 形成对比。
- MySQL (锚定 4 个节点): MySQL 是最流行的关系型数据库，使用 SQL 查询语言。MySQL 在后端开发中用于持久化存储。MySQL 与 Redis 常配合使用，前者负责持久化后者负责缓存。MySQL 是 LAMP 架构的 M。
- RESTful API (锚定 4 个节点): RESTful API 以 HTTP 方法映射资源操作，是后端网关与微服务对外暴露接口的常用风格。
- Vue (锚定 3 个节点): Vue 以响应式数据绑定与虚拟 DOM 构建 UI，组合式 API 管组织逻辑，与 React 共同主导前端开发生态。
- 读者 (锚定 2 个节点): 读者是作品的接受者。读者的期待受体裁影响。读者通过主题获得共鸣。节奏和视角影响读者体验。读者是写作的最终服务对象。了解读者让写作更有针对性。
- DOM (锚定 2 个节点): DOM 是浏览器解析 HTML 后构建的树形节点模型，JavaScript 操作 DOM 触发渲染更新，是虚拟 DOM 要优化的对象。
- TypeScript (锚定 2 个节点): TypeScript 为 JavaScript 添加静态类型系统，通过接口约束提升代码质量，是大型前端项目的标配语言。
