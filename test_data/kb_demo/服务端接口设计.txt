# 服务端接口设计笔记

## Node.js
Node.js 让 JavaScript 可以运行在服务端，从而用同一门语言完成前后端开发。
Node.js 基于事件循环与非阻塞 IO，适合高并发 IO 密集型服务。

## RESTful API
RESTful API 是一种基于 HTTP 的资源化 Web 服务架构风格。
RESTful API 用 HTTP 动词操作资源，用状态码表达处理结果。

## HTTP
HTTP 是无状态的应用层协议，请求与响应由报文承载。
HTTP 的状态码分为 2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误。

## MySQL
MySQL 是最常用的关系型数据库，通过 SQL 完成数据定义与查询。
MySQL 的索引可以显著加快查询速度，事务保证数据一致性。

## SQL
SQL 是结构化查询语言，用于操作关系型数据库。
SQL 分为 DDL 与 DML 两类语句，分别负责结构定义与数据读写。
