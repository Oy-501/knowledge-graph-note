# 示例知识库：网站开发（Markdown 条目格式）

## 网站开发 (Web Development)
- 别名: Web Development, 建站, 网站建设
- 关系: HTML, CSS, JavaScript, 前端开发, 后端开发, 域名, 服务器
- domain: web
- bridge_sentence: 网站开发是把域名、服务器、前端页面与后端接口组合成一个可访问站点的工作总称

## HTML
- 别名: 超文本标记语言
- 关系: 网站开发, CSS, DOM, 语义化
- domain: web
- bridge_sentence: HTML 用标签描述页面结构与语义，是浏览器渲染页面的输入

## CSS
- 关系: HTML, 样式, 响应式布局, 盒模型
- domain: web
- bridge_sentence: CSS 通过盒模型与层叠规则控制页面的视觉表现与响应式布局

## DOM
- 别名: 文档对象模型
- 关系: HTML, JavaScript, 事件
- domain: web
- bridge_sentence: DOM 把 HTML 文档映射成可编程的节点树，JavaScript 通过它修改页面

## 响应式布局
- 别名: Responsive Design
- 关系: CSS, 媒体查询, 移动端, 视口
- domain: web
- bridge_sentence: 响应式布局用媒体查询与弹性栅格让同一套页面适配不同屏幕宽度

## 前端路由
- 关系: Vue, React, SPA, 浏览器历史
- domain: web
- bridge_sentence: 前端路由在单页应用中接管地址变化，避免整页刷新

## 跨域
- 别名: CORS, 同源策略
- 关系: HTTP, 浏览器, 后端开发, 反向代理
- domain: web
- bridge_sentence: 跨域问题的根源是浏览器的同源策略，常见解法是 CORS 响应头或反向代理

## 反向代理
- 关系: Nginx, 跨域, 服务器, 负载均衡
- domain: web
- bridge_sentence: 反向代理把外部请求转发给内部服务，同时承担 HTTPS 终止与负载均衡

## 部署
- 别名: Deployment
- 关系: 服务器, Docker, 域名, 持续集成
- domain: web
- bridge_sentence: 部署是把构建产物发布到服务器并对外提供访问的最后一个环节
