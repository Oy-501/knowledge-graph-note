# 知识图谱笔记 · 产品落地页

课程设计答辩用的产品介绍页。独立静态页面，不依赖项目后端。

## 定调说明

- **受众**：课程设计评审 / 答辩老师。场景要求可信、专业、有工程深度。
- **调性**：杂志编辑（Editorial）× 中文出版物 —— 暖纸底、发丝线、栏目编号、
  首字下沉、衬线大标题。
- **字体**：展示字 Fraunces + 思源宋体（离线回退本地宋体，编辑感不丢）；
  正文思源黑体；编号与数据 Space Mono（`tabular-nums`）。
- **配色**：暖纸 `#f5f1e8` / 墨黑 `#1c1813` / 朱砂 `#c13b2a`（60/30/10）。
  朱砂取"批注与印章"的语义，是全页唯一强调色，只用于关键动作与印章。
- **记忆点**：① 朱砂「谱」字印章（旋转 -3°、墨黑投影、内描边）；
  ② 首屏 SVG 图谱实时演示"散点收敛成学习主线"——产品价值主张的视觉化。

## 运行

```bash
# 任选其一：
# 1. 直接双击 index.html（字体走 CDN，离线时自动回退本地字体）
# 2. 本地服务
cd landing && python -m http.server 8088
# 打开 http://127.0.0.1:8088
```

## 令牌映射

| 层 | 文件 | 内容 |
|---|---|---|
| 令牌 | `styles/tokens.css` | 色彩 / 三套字体 / 1.25 字阶 / 间距梯度 / 动效时长 |
| 基础 | `styles/base.css` | 重置、排版、`:focus-visible` 焦点圈、降级动效 |
| 组件 | `styles/components.css` | 刊头 / 首屏 / 图谱 / 栏目 / 四维 / 流水线 / 数字 / 架构 / 页脚 |
| 行为 | `scripts/main.js` | 图谱收敛动效（定种子可复现）、滚动入场、跑马灯 |

## 自检结果（均为实测，非目测）

- **对比度**：正文 10.46:1 · 栏目编号 6.67:1 · 图注/页脚 5.25:1 · 大字标题 15.66:1 ——
  全部达标。初版 `--muted` 只有 4.1:1，已压深到 `#6c6354`。
- **降级动效**：模拟 `prefers-reduced-motion: reduce`，1.2s 后节点已全部就位、连线已画满、
  跑马灯 `animation-name: none`、标题位移 `none` —— 即入场动画不执行，直接呈现终态。
- **焦点可见**：真实 Tab 键落到跳转链接，`outline: 2px solid rgb(193,59,42)`、`offset: 2px`。
- **响应式**：1440 / 768 / 375 三档实测，`scrollWidth` 均未超出视口（无横向溢出）；
  图谱在图注下方留白，图注不再压住节点（初版绝对定位在窄屏会压住底排）。
- **运行期**：三档宽度均 **0 条未捕获异常**。
- **可访问性**：跳转链接、唯一 `h1`、`header/main/section/footer` 语义地标、
  SVG 带 `role="img"` + `aria-label`、跑马灯与装饰印章标 `aria-hidden`。
- **反 AI 味清单**：12 项逐条过 —— 无紫蓝渐变、无居中三卡、无禁用字体、无空泛文案、
  每屏有发丝线或色块分层，状态覆盖（悬停/按下/聚焦/禁用态仅按钮组适用）。
