# domain: software

## JavaScript
别名: JS, ECMAScript, ECMA-262
关系: TypeScript, Node.js, React, Vue, Angular, Webpack, 前端开发
JavaScript 是一门动态弱类型、面向原型的脚本语言，广泛用于 Web 前端开发。它与 TypeScript 生态紧密结合，通过 Node.js 扩展到后端开发。在前端领域，React 和 Vue 都基于 JavaScript 构建，Webpack 负责模块打包。JavaScript 与 TypeScript 的关系是超集关系，TypeScript 添加了静态类型系统。

## TypeScript
别名: TS
关系: JavaScript, Node.js, React, Vue, 前端开发
TypeScript 是 JavaScript 的超集，由微软开发，添加了静态类型系统。TypeScript 编译后生成 JavaScript 代码，可以在 Node.js 运行时执行。React 和 Vue 都对 TypeScript 提供了一等公民支持。TypeScript 让前端开发的大型项目更易维护。

## Python
别名: py, CPython
关系: 机器学习, 人工智能, 数据分析, Django, Flask, FastAPI, 后端开发
Python 是一门简洁优雅的高级语言，广泛用于机器学习和人工智能领域。在数据分析方面，Python 拥有 NumPy 和 Pandas 等强大库。后端开发中，Django、Flask 和 FastAPI 是三大流行框架。Python 与机器学习密不可分，深度学习框架如 TensorFlow 也以 Python 为主要接口。

## Go
别名: Golang, golang
关系: 微服务, 后端开发, Docker, Kubernetes
Go 语言由 Google 开发，以并发性能和简洁语法著称。Go 在微服务架构中应用广泛，许多后端开发团队选择 Go 构建高性能服务。Docker 和 Kubernetes 都是用 Go 语言编写的。Go 的并发模型 goroutine 非常适合微服务间通信。

## Rust
别名: rustc
关系: 系统编程, WebAssembly, C++, 嵌入式
Rust 是一门注重内存安全和零成本抽象的系统编程语言。Rust 可编译为 WebAssembly 在浏览器运行。与 C++ 相比，Rust 通过所有权机制消除了数据竞争。Rust 在嵌入式开发中也越来越受欢迎，提供了安全的底层控制能力。

## Java
别名: JVM
关系: Spring, 后端开发, 微服务, Maven
Java 是企业级后端开发的主流语言，基于 JVM 运行。Spring 框架是 Java 生态的核心，广泛用于微服务架构。Maven 是 Java 项目的主要构建工具。Java 在大规模分布式系统中表现稳定。

## C++
别名: CPP, cpp, C Plus Plus
关系: C语言, 嵌入式, 系统编程, Qt, 游戏开发
C++ 是在 C语言基础上发展而来的面向对象编程语言，广泛用于系统编程和游戏开发。C++ 与 C语言高度兼容，在嵌入式领域用于编写高性能固件。Qt 是基于 C++ 的跨平台 GUI 框架。C++ 的模板元编程能力强大但复杂。

## C语言
别名: C, ANSI C
关系: C++, 嵌入式, 操作系统, 系统编程
C语言是底层系统编程的基石，操作系统如 Linux 内核主要用 C语言编写。C语言是 C++ 的前身，语法简洁但功能强大。在嵌入式开发中，C语言是最常用的编程语言，直接操作硬件。C语言与操作系统和嵌入式关系密切。

## React
别名: ReactJS, React.js
关系: JavaScript, 前端开发, TypeScript, Redux, Webpack, Vue
React 是 Facebook 开发的组件化前端框架，基于 JavaScript 和 TypeScript。React 采用虚拟 DOM 提升渲染性能，常配合 Redux 做状态管理。React 与 Vue 是前端开发领域的两大主流选择。Webpack 通常用于打包 React 应用的模块。

## Vue
别名: Vue.js, VueJS
关系: JavaScript, 前端开发, TypeScript, Webpack, React
Vue 是一款渐进式 JavaScript 前端框架，由尤雨溪开发。Vue 对 TypeScript 提供良好支持，学习曲线比 React 更平缓。Vue 与 React 常被对比，都是前端开发的流行选择。Vue 项目通常使用 Webpack 或 Vite 进行构建。

## Angular
别名: AngularJS
关系: JavaScript, 前端开发, TypeScript
Angular 是 Google 维护的企业级前端框架，完全基于 TypeScript 构建。与 React 和 Vue 不同，Angular 提供完整的 MVC 架构。Angular 依赖 JavaScript 和 TypeScript 的最新特性。Angular 适合大型前端开发团队使用。

## Node.js
别名: Node, NodeJS, nodejs
关系: JavaScript, 后端开发, Express, npm, Webpack
Node.js 是基于 V8 引擎的 JavaScript 运行时，让 JavaScript 可以用于后端开发。Express 是 Node.js 上最流行的 Web 框架。npm 是 Node.js 的包管理器，拥有全球最大的开源库生态。Webpack 依赖 Node.js 环境运行。Node.js 与 JavaScript 共享事件驱动模型。

## Express
别名: Express.js
关系: Node.js, 后端开发, RESTful API
Express 是 Node.js 上的轻量级 Web 框架，广泛用于后端开发。Express 常用于构建 RESTful API 服务。Express 基于 Node.js 的 HTTP 模块封装，是 Node.js 生态中最基础的框架。

## Django
别名: 
关系: Python, 后端开发, RESTful API
Django 是 Python 生态中全栈式后端框架，自带 ORM 和 Admin。Django 适合快速构建后端开发项目和 RESTful API。Django 与 Flask 和 FastAPI 同为 Python Web 框架。Django 遵循 MTV 架构模式。

## Flask
别名: 
关系: Python, 后端开发
Flask 是 Python 的轻量级 Web 框架，灵活性高于 Django。Flask 适合小型后端开发项目。Flask 与 Django 互补，前者轻量后者全栈。Flask 基于 Python 的 WSGI 规范。

## FastAPI
别名: Fast API
关系: Python, 后端开发, RESTful API
FastAPI 是基于 Python 3.6+ 的高性能异步 Web 框架，自动生成 RESTful API 文档。FastAPI 比 Django 和 Flask 更快，利用 Python 的 async 特性。FastAPI 使用 Pydantic 做数据验证。FastAPI 是后端开发的新兴选择。

## Spring
别名: Spring Boot, Spring Framework
关系: Java, 后端开发, 微服务
Spring 是 Java 生态最核心的企业级框架。Spring Boot 简化了 Spring 的配置，广泛用于微服务架构。Spring 与 Java 深度绑定，是 Java 后端开发的标准。Spring Cloud 提供微服务治理能力。

## Docker
别名: 容器, container
关系: Kubernetes, 微服务, DevOps, Go, Linux
Docker 是容器化技术的代名词，用 Go 语言编写。Docker 与 Kubernetes 配合实现微服务的部署和编排。Docker 是 DevOps 流程的核心工具。Docker 基于 Linux 的 cgroup 和 namespace 技术。Docker 让微服务部署更一致。

## Kubernetes
别名: K8s, k8s
关系: Docker, 微服务, DevOps, Go
Kubernetes 简称 K8s，是容器编排的事实标准，用 Go 语言编写。Kubernetes 管理大量 Docker 容器，实现微服务的自动伸缩。Kubernetes 是 DevOps 和云原生的核心技术。Kubernetes 与 Docker 的关系是编排器与容器引擎。

## Redis
别名: 
关系: 数据库, 缓存, 后端开发
Redis 是高性能内存数据库，常用作缓存。Redis 在后端开发中用于减轻主数据库压力。Redis 与 MySQL 和 PostgreSQL 互补。Redis 支持多种数据结构，是 NoSQL 数据库的代表。

## MySQL
别名: 
关系: 数据库, SQL, 后端开发
MySQL 是最流行的关系型数据库，使用 SQL 查询语言。MySQL 在后端开发中用于持久化存储。MySQL 与 Redis 常配合使用，前者负责持久化后者负责缓存。MySQL 是 LAMP 架构的 M。

## PostgreSQL
别名: Postgres, postgres
关系: 数据库, SQL, 后端开发
PostgreSQL 是功能强大的开源关系型数据库，支持 SQL 和 JSON。PostgreSQL 比 MySQL 更严格遵循 SQL 标准。PostgreSQL 在后端开发中用于复杂查询场景。PostgreSQL 和 MySQL 是关系型数据库的两大选择。

## MongoDB
别名: Mongo
关系: 数据库, NoSQL, 后端开发
MongoDB 是流行的文档型 NoSQL 数据库。MongoDB 不使用 SQL，而用 BSON 格式存储。MongoDB 在后端开发中适合灵活数据结构。MongoDB 与 Redis 同为 NoSQL 数据库但用途不同。

## 数据库
别名: Database, DB
关系: MySQL, PostgreSQL, MongoDB, Redis, SQL, NoSQL
数据库是后端开发的基础设施，分为关系型数据库和 NoSQL 数据库。MySQL 和 PostgreSQL 是关系型数据库的代表，使用 SQL。MongoDB 和 Redis 是 NoSQL 数据库。数据库选型影响后端架构设计。

## SQL
别名: Structured Query Language
关系: MySQL, PostgreSQL, 数据库
SQL 是结构化查询语言，用于操作关系型数据库。MySQL 和 PostgreSQL 都支持 SQL。SQL 是数据库领域的通用语言。SQL 与 NoSQL 形成对比。

## NoSQL
别名: 
关系: MongoDB, Redis, 数据库
NoSQL 指非关系型数据库，包括 MongoDB 和 Redis 等。NoSQL 不使用 SQL，适合非结构化数据。NoSQL 与 SQL 数据库互补。NoSQL 牺牲一致性换取可用性。

## 微服务
别名: Microservice, Microservices, 微服务架构
关系: Docker, Kubernetes, 后端开发, Spring, Go, RESTful API
微服务是一种将应用拆分为独立服务的架构。Docker 和 Kubernetes 是微服务部署的基础。Go 语言和 Spring 都适合构建微服务。微服务之间常通过 RESTful API 通信。微服务架构提升了系统的可扩展性。

## RESTful API
别名: REST, restful, REST API
关系: 后端开发, Express, FastAPI, Django, 微服务, GraphQL
RESTful API 是基于 HTTP 的接口设计风格，广泛用于后端开发。Express 和 FastAPI 都适合构建 RESTful API。微服务之间通过 RESTful API 通信。RESTful API 与 GraphQL 是两种不同的 API 设计理念。

## GraphQL
别名: 
关系: 前端开发, 后端开发, RESTful API
GraphQL 是 Facebook 开发的查询语言，替代 RESTful API。GraphQL 让前端开发按需查询数据。GraphQL 与 RESTful API 是两种竞争的 API 方案。GraphQL 可以减少前后端交互次数。

## 前端开发
别名: 前端, Frontend, frontend
关系: JavaScript, TypeScript, React, Vue, Angular, Webpack, HTML, CSS
前端开发关注用户界面，以 JavaScript 为核心语言。React 和 Vue 是前端开发的两大框架。TypeScript 在前端开发中越来越普及。Webpack 是前端开发的模块打包工具。前端开发涉及 HTML 和 CSS 基础技术。

## 后端开发
别名: 后端, Backend, backend
关系: Node.js, Python, Java, Go, 数据库, RESTful API, 微服务, Docker
后端开发处理业务逻辑和数据，常用语言有 Node.js、Python、Java 和 Go。后端开发离不开数据库和 RESTful API。微服务架构是后端开发的趋势。Docker 简化了后端开发的部署。

## DevOps
别名: CI/CD
关系: Docker, Kubernetes, Git, 微服务, Linux
DevOps 是开发和运维一体化实践，强调自动化 CI/CD。Docker 和 Kubernetes 是 DevOps 的核心工具。Git 是 DevOps 中版本控制的基础。DevOps 与微服务架构相辅相成。DevOps 依赖 Linux 运行环境。

## Git
别名: git
关系: GitHub, GitLab, DevOps
Git 是分布式版本控制系统，是 DevOps 的基础。GitHub 和 GitLab 是基于 Git 的代码托管平台。Git 让团队协作开发更高效。Git 是软件开发的标准工具。

## GitHub
别名: github
关系: Git, 开源
GitHub 是全球最大的代码托管平台，基于 Git。GitHub 是开源项目的聚集地。GitHub 与 Git 密不可分，是 Git 的云端实现。GitHub 被 Microsoft 收购。

## Webpack
别名: 
关系: 前端开发, JavaScript, React, Vue, Node.js
Webpack 是前端开发的模块打包工具。Webpack 依赖 Node.js 环境运行。React 和 Vue 项目通常使用 Webpack 打包。Webpack 将 JavaScript 模块及其依赖打包为静态资源。

## HTML
别名: 
关系: 前端开发, CSS, JavaScript
HTML 是前端开发的标记语言基础，定义网页结构。HTML 与 CSS 和 JavaScript 共同构成前端开发三件套。CSS 负责 HTML 的样式。JavaScript 为 HTML 添加交互行为。

## CSS
别名: 
关系: 前端开发, HTML
CSS 是层叠样式表，控制 HTML 的视觉呈现。CSS 是前端开发的基础之一。CSS 与 HTML 密不可分。CSS 预处理器如 Sass 扩展了 CSS 能力。

## 操作系统
别名: OS
关系: C语言, Linux, 系统编程
操作系统是管理硬件资源的系统软件。C语言是编写操作系统的首选语言。Linux 是最流行的开源操作系统。操作系统是系统编程的基础平台。

## Linux
别名: linux
关系: 操作系统, DevOps, Shell, 嵌入式, Docker
Linux 是开源的操作系统内核。Linux 在 DevOps 和服务器领域占主导。Docker 基于 Linux 的容器技术。Linux 也用于嵌入式系统。Linux 与 C语言关系密切，内核用 C语言编写。

## 系统编程
别名: 
关系: C语言, C++, Rust, 操作系统
系统编程关注底层性能，常用 C语言、C++ 和 Rust。系统编程是操作系统和嵌入式的基础。Rust 是系统编程的新兴语言，提供内存安全。系统编程直接操作硬件资源。

## 机器学习

机器学习是人工智能的核心分支。Python 是机器学习的主要语言。深度学习是机器学习的子领域。机器学习应用于自然语言处理和计算机视觉。机器学习需要大量数据训练模型。

## 人工智能
别名: AI, ai
关系: 机器学习, 深度学习, 自然语言处理, 计算机视觉
人工智能是模拟人类智能的技术总称。机器学习和深度学习是人工智能的核心方法。人工智能在自然语言处理和计算机视觉领域取得突破。人工智能与 Python 生态紧密结合。

## 深度学习
别名: DL, dl
关系: 机器学习, 人工智能, 神经网络, 计算机视觉
深度学习是基于神经网络的机器学习方法。深度学习是人工智能的重要分支。深度学习在计算机视觉领域表现卓越。深度学习依赖 Python 生态的 TensorFlow 和 PyTorch。

## 神经网络
别名: Neural Network, NN
关系: 深度学习, 机器学习, 人工智能
神经网络是深度学习的基础模型结构。神经网络模拟人脑神经元连接。神经网络是机器学习和人工智能的核心。神经网络包括卷积神经网络和循环神经网络等类型。

## 自然语言处理

关系: 人工智能, 机器学习, 深度学习
自然语言处理简称 NLP，是人工智能的重要分支。自然语言处理利用机器学习和深度学习技术。自然语言处理处理文本和语音。自然语言处理与计算机视觉并列。

## 计算机视觉
别名: CV, cv
关系: 人工智能, 深度学习, 神经网络
计算机视觉简称 CV，让计算机理解图像。计算机视觉依赖深度学习和神经网络。计算机视觉是人工智能的重要应用。计算机视觉与自然语言处理是 AI 两大方向。
